Privacy policy

Last updated 20 November 2026. Applies to the Plainwire extension and this website.

Short version: Plainwire collects nothing. It has no telemetry, no analytics, no account and no server of its own.

The extension

  • No telemetry or analytics. Plainwire does not record or report how you use it, which commands you run, errors, or anything about your machine.
  • No account. There is no sign-in, licence key or registration, so we hold no personal data about you.
  • No network calls of its own. The only network traffic Plainwire creates is the HTTP requests you send, and they go only to the URLs in those requests. There is no update check, no ping, and no proxy or relay operated by us in between.
  • Your files stay yours. Requests are saved as .http files in your workspace, where you put them. Imports (Thunder Client, Postman, cURL) are converted locally from the file or text you choose and are not uploaded anywhere.
  • History is stored locally. The list of requests you have sent is kept in VS Code’s storage for the extension on your own computer. It is not synced or uploaded by Plainwire. It may contain URLs, headers and bodies you sent, so treat it like any other local data on your machine.
  • Secrets. Values in http-client.private.env.json or .env files are read locally when a request uses them and sent only as part of that request. Keep those files out of git (add them to .gitignore).

Your editor and the extension registry

VS Code, Cursor, Windsurf and VSCodium have their own telemetry settings, and extension registries count downloads. Those are controlled by the editor or registry vendor, not by Plainwire, and are covered by their privacy policies.

This website

This site is static HTML hosted on GitHub Pages. It sets no cookies, loads no third-party scripts, fonts or trackers, and has no analytics or forms. The online converters run as a script from this site inside your browser: what you paste or choose is converted in memory, is never sent anywhere, and is gone when you close the tab. GitHub, as the host, may process technical data such as IP addresses in its server logs; see the GitHub General Privacy Statement.

Verify it

Plainwire is open source under the MIT licence. The full source is on GitHub, so you can confirm these statements by reading the code or by watching the extension’s traffic.

Changes

If this policy changes, the new version will be published on this page with a new date, and the change will be visible in the repository history.

Contact

Questions about privacy: open an issue at github.com/janwan2003/vscode-api-client/issues. Please do not paste secrets or tokens into issues.
