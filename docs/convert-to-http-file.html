Postman, Thunder Client & cURL to .http converter

Paste a Postman collection (v2.0/v2.1), a Postman environment, a Thunder Client collection export or thunder-tests/*.json file, an OpenAPI / Swagger definition (JSON or YAML; details), or a cURL command. You get plain .http files, one per folder, plus an http-client.env.json for environments. The files work in REST Client, Plainwire, httpYac and the JetBrains HTTP Client.

The conversion runs in this page with the same code as the Plainwire extension and CLI. Your collection is not uploaded or stored, and the page makes no network requests. Exported environments can still hold real tokens, so check them before you commit the files.

    FAQ
    
    
    Is my collection sent anywhere?
    No. The converter is a script on this page (source). It reads the text you paste or the files you choose, converts them in memory and lets you copy or download the result. Nothing is uploaded and nothing is stored after you close the tab.
    
    
    Can I convert a whole thunder-tests folder?
    Yes. Choose all of its JSON files at once (for example thunderclient.json, thunderCollection.json and thunderEnvironment.json, or the collections/ and environments/ files of the newer layout) and they are combined into one result.
    
    
    Postman v1 collections?
    Not supported. Open the collection in Postman and export it again as Collection v2.1.
    
    
    How is this different from the extension’s import?
    It is the same converter. In VS Code, Plainwire: Import from Thunder Client / Postman / cURL writes the files straight into your workspace; the CLI does it with plainwire import.
